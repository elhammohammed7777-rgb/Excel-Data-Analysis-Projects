# Excel Data Analysis Projects

## 📌 Overview

This repository contains a collection of data analysis projects developed using Microsoft Excel. The projects focus on data cleaning, exploratory data analysis, KPI tracking, and generating actionable business insights from structured datasets.

## 🛠️ Tools & Skills

* Microsoft Excel
* Data Cleaning and Preparation
* PivotTables and PivotCharts
* Excel Formulas and Functions
* Slicers and Interactive Reports
* KPI Analysis and Business Reporting
* Data Visualization

## 📂 Projects

### 1. HR Analytics

**Objective:** Analyze employee data to identify workforce trends and understand employee attrition.

**Key Analysis:**

* Employee demographics and workforce distribution
* Attrition patterns
* Compensation and job-related trends

**Tools:** Excel, PivotTables, PivotCharts

[View Project](./HR-Analytics/)
[View Dashboard](./HR-Analytics/HR.png)

### 2. Hypermarket Sales Analysis

**Objective:** Analyze sales transactions across three branches to evaluate business performance.

**Key Analysis:**

* Revenue and transaction distribution by branch
* Product line performance
* Customer purchasing patterns
* Sales performance by time and payment method

**Tools:** Excel, PivotTables, PivotCharts

[View Project](./Hypermarket-Sales/)

### 3. Global Companies Analysis

**Objective:** Explore global company data to understand geographic distribution and compare company representation across countries.

**Key Analysis:**

* Company distribution by country
* Comparison of the USA and China
* Geographic patterns in the dataset

**Tools:** Excel, PivotTables, Charts

[View Project](./Global-Companies/)

### 4. Cost of Living Analysis

**Objective:** Analyze cost-of-living data to compare expenses across categories and identify major cost drivers.

**Key Analysis:**

* Expense categorization
* Comparison across 10 expense categories
* Housing and transportation cost analysis

**Tools:** Excel, Data Cleaning, PivotTables, Charts

[View Project](./Cost-of-Living/)

## 🎯 Key Goals

* Transform raw data into structured and meaningful information.
* Identify trends and patterns using Excel analytical tools.
* Track business metrics and support data-driven decision-making.
* Present findings through clear and organized reports.
